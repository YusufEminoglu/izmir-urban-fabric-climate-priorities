# Figure Style Guide — ICUS 2026 İzmir Grid Paper

This document establishes the official style guidelines for all figures in the İzmir grid-based urban resilience paper to ensure consistency in layouts, fonts, resolutions, styles, and color palettes.

---

## 🎨 Unified Color Palette

All figures must strictly utilize the following color palette to establish a cohesive visual language throughout the paper.

### Main Colors
*   **Primary Gold:** `#E9B420` (used for highlighting, core categories, and accents)
*   **Secondary Grey/Muted Slate:** `#8E8E8D` (used for background boundaries, grids, and neutral elements)

### Secondary Colors (Sadi Colors)
*   **Soft Pink/Red:** `#DDB5B5`
*   **Soft Orange/Peach:** `#EBCB9C`
*   **Soft Teal/Green:** `#A0CBBF`
*   **Soft Rose/Salmon:** `#DEA6A3`
*   **Soft Purple/Lavender:** `#C5AFD5`

### Geographic & Context Elements
*   **Land Surface Background:** `#F8FAFC` (Slate-50) or `#F1F5F9` (Slate-100)
*   **Water Bodies / Sea:** `#E2E8F0` (Slate-200) or `#CBD5E1` (Slate-300)
*   **Boundary Outlines:** `#64748B` (Slate-500) or `#8E8E8D` (Secondary Grey)

## 📐 Layout & Typography

### Fonts & Labels
*   **Font Family:** `sans-serif` (specifically Arial, Helvetica, or clean system defaults).
*   **Title Size:** `12 pt` to `13 pt` (Bold, color `#1E293B`).
*   **Axis/Legend Labels:** `8.5 pt` to `10 pt` (Color `#334155`).
*   **Annotations:** `8 pt` (Color `#475569`).

### Grid and Background
*   All multi-panel figures should use a consistent light background `#F8FAFC` to blend with the document.
*   Panels must contain thin borders (`color="#cbd5e1"`, `linewidth=0.8`) with elegant drop shadows where appropriate.
*   Plot margins should be tightly adjusted (`plt.tight_layout()` or explicit margins) to maximize space.

### Resolution & Output
*   All images must be exported at `dpi=180` or higher to ensure high-fidelity print quality.
*   Format: PNG (lossless compression) stored in `outputs/figures/`.

---

## 🛠️ Code Architecture

*   **Modular Scripts:** Each figure must be generated by its own **standalone Python script** located in `scripts/`.
*   Never write a single script that generates multiple main figures. This ensures that updates to one figure do not inadvertently break others and allows for parallel development.
