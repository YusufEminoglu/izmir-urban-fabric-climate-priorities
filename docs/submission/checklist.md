# ICUS 2026 Submission Checklist

## Before Writing

- [ ] Freeze title direction.
- [ ] Select case city and analysis unit.
- [ ] Fill `abstracts/icus2026_abstract_writing_prompt.md` Section C.
- [ ] Freeze PlanX plugin version.
- [ ] Decide language: Turkish or English.
- [ ] Confirm author list, affiliations, emails, and ORCID information.

## Abstract Requirements

- [ ] 500-750 words.
- [ ] Aim, method, findings/expected findings, and originality are clear.
- [ ] No figure, table, image, reference list, or author-identifying text inside abstract body.
- [ ] 3-5 Turkish keywords.
- [ ] 3-5 English keywords.
- [ ] Turkish and English title prepared.
- [ ] Turkish and English abstract prepared.
- [ ] Language edited manually before submission.

## Compliance

- [ ] Original and not submitted elsewhere.
- [ ] Similarity checked and below 20 percent.
- [ ] No unreviewed AI-generated prose in the submitted text.
- [ ] Method claims match actual available data and PlanX outputs.
- [ ] Screening-model limitations stated honestly.

## CMT Submission

- [ ] CMT account available.
- [ ] Abstract text ready for CMT fields.
- [ ] Word-compatible abstract file ready if the system requests upload.
- [ ] Submission completed before 29 June 2026.
- [ ] Confirmation saved under `docs/submission/`.
