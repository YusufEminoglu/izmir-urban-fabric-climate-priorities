# Data Folder

Use this folder for the ICUS 2026 case study data.

```text
data/
|-- 00_external/   # institutional or hand-collected reference layers
|-- 01_raw/        # downloaded raw open data
|-- 02_interim/    # clipped, cleaned, reprojected layers
`-- 03_processed/  # PlanX-ready and analysis-ready outputs
```

All final layers should document source, date, CRS, preprocessing, and field definitions.
